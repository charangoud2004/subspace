# Subspace

Repository containing various projects and utilities.

## Projects

### [Outreach Pipeline](./outreach-pipeline)

Automated B2B cold outreach pipeline that finds lookalike companies, identifies decision-makers, verifies emails, and sends personalized outreach.

**Key Features:**
- 🔍 Lookalike company discovery via Ocean.io
- 👔 Decision-maker identification via Prospeo
- ✉️ Email verification via Hunter.io
- 📧 Automated outreach via Brevo
- 🛡️ Safety checkpoint before sending
